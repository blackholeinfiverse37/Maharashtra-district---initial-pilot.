# Dataset inventory

Every dataset the AIAIC District Intelligence Dashboard uses, or has checked. Compiled on 2026-11-05.

**How this was compiled.** Only from what is in this folder and its docs:

- this repository's code;
- its recorded backend answers in `src/test/recorded/`;
- `README.md` and `REVIEW_PACKET.md`;
- the WDRA CSVs beside the repository;
- AIAIC's dataset register, `AIAIC_DATASET_REGISTER_V1_NASHIK.csv`, which is kept outside this repository in the
  "Hemanth's files" folder. It is cited below as "the register".

No source website or API was contacted on 2026-11-05. "Last checked" therefore means the date of the newest record of
that dataset held here, not a live check today. **Not verified** means it could not be confirmed from the repo or its
docs.

**How the dashboard gets data.** It reads one AIAIC backend (`VITE_AIAIC_API`, see `src/data_adapter/aiaicApi.js`). It
never calls Agmarknet, CGWB, GSDA, DES, e-NAM or the weather provider itself. The only dataset held inside the page is
the WDRA warehouse list (`src/data/wdra_warehouses.json`).
